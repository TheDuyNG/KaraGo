# KaraGo Agent Instructions

Before making changes, read:

1. `docs/KaraGo Language and Theme Requirements.md`
2. `docs/KaraGo Redesign Agent Prompt — Redesign Branch.md`

Both documents are mandatory requirements for the redesign.

After reading them:

1. Audit the existing KaraGo source code.
2. Identify KEEP / REFACTOR / REPLACE / DELETE areas.
3. Inspect and preserve useful API mappings and business logic.
4. Create a short implementation plan.
5. Begin the redesign.
6. Remove obsolete UI code after its replacement is working.
7. Keep the frontend compatible with the future backend API.
